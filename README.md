# Petites annonces — module Paheko

Permet aux membres de publier et consulter des annonces d’occasion ou de services.

## Installation

Le dossier du module est `modules/petites_annonces/`. Utilisez ce dossier avec la procédure d’installation des modules personnalisés correspondant à votre instance Paheko. Ne déplacez pas `module.ini` hors de ce dossier.

Vérifiez la compatibilité avec la version de Paheko utilisée avant le déploiement.
