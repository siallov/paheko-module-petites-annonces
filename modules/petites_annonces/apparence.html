Présentation du module
{{:input type="select" name="display_theme" required=true label="Thème utilisé" options=$display_themes default="defaut" source=$module.config}}

Le thème Paheko fonctionne sans personnalisation du module web. Le thème commun utilise les fichiers _module_head.html et _module_foot.html installés dans le module web, ainsi que son CSS et ses réglages. Sur une nouvelle installation, laissez le thème par défaut tant que ces fichiers ne sont pas installés.
